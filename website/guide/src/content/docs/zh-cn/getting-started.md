## 在 Windows 上安装

1. 打开[版本下载页面](https://github.com/zhaiyusci/mengshee/releases/latest)。
2. 下载并运行 `Mengshee-…-Setup.exe` 安装包。
3. 按安装向导完成安装。如果需要新建或编辑 LaTeX 批注，保留安装程序提供的 LaTeX 支持组件。
4. 启动 Mengshee，通过**文件 → 打开**选择 PDF。

查看已有 LaTeX 批注不需要再次编译，因为 PDF 已保存渲染后的外观；新建或修改批注才需要渲染运行库。

需要中文、额外宏包或使用本地 TeX Live 时，请先按 [LaTeX 排版环境配置](../latex-notes/#配置-latex-排版环境)完成设置。

## 找到需要的工具

主工具栏的模式选择器按任务分组：阅读与批注、交叉引用、OCR、页面编辑、Reading Views 和校对。切换模式会显示相应控件，但不会自动启动其中所有工具。将鼠标悬停在图标上可查看工具名称。

可以先试一个简单流程：打开 PDF，调整为适合宽度，高亮一句话，然后另存一份副本。重新打开副本，确认批注已经保存。

## 保存修改

使用**保存**更新当前 PDF；使用**另存为**保留原件并创建编辑后的副本。文档的已修改标记表示仍有未保存的内容。撤销和重做适用于当前会话中支持的编辑操作，不能代替保留原件。

如果某项工具不可用，先检查是否打开了本地 PDF，以及文件是否允许编辑。切换模式不会绕过文档权限。更多说明见[常见问题](../troubleshooting/)。
