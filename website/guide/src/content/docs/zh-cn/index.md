Mengshee 是面向科学与工程工作的 PDF 阅读和批注工作台。你可以跟随文献中的引用、在论文旁写下公式、整理校对意见，并导出用于分享的文档。

本指南对应 Windows 版 **2026.0.26.9**。英文和简体中文拥有相同章节；使用语言选择器可切换到对应页面。软件中的名称可能随界面语言变化，因此指南会说明工具用途，并在需要时列出英文名称，避免仅凭图标找功能。

## 先区分显示与文档修改

阅读设置改变你看到文档的方式，页面编辑和批注则改变保存的内容。**按 View 阅读**不会裁切 PDF；调整页面大小会改变可见范围。打印时的自动纸张方向只转动输出纸张，不会旋转保存的 PDF 页面。

编辑后保存 PDF 才能保留修改。导出扁平化 PDF 或图片时，应保留可编辑的原件。接收者无需安装 StemTeX 即可查看已渲染的 LaTeX 批注；再次编辑其源码则需要 Mengshee 和渲染运行库。
