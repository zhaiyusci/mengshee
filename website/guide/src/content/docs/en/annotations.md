## Mark or comment on a passage

Choose a markup tool such as Highlight, Underline, or Strikeout, then select the relevant text. Markup tools support repeated use; press **Esc** when you are finished. For a text box or note, choose its tool, place it on the page, and enter your comment. Text-entry and image-placement tools complete one insertion at a time.

Select an existing annotation to move it or use its frame handles. Open its properties to change the options supported by that annotation, such as text size, color, border, and opacity. Not every annotation type has every option.

## Set defaults for a tool

Right-click the annotation's **toolbar button** to configure that tool's defaults. This uses the same property-editing path as an individual object. Tools remember their own settings; a highlight and a text box do not need to share colors. Changing a default is not a bulk edit of existing annotations.

## Insert an image

1. Choose the image annotation tool.
2. Select **Insert Image from File…** or **Insert Image from Clipboard**.
3. Place the image on the page and resize it with its handles.

The clipboard option is available when a usable image is present. Each insertion asks for its source rather than silently reusing the previous image. Image annotations and stamps preserve their aspect ratio when resized.

## Adjust a callout

Move the arrow tip to the passage. Drag the elbow toward the desired side of the text box: the short segment attaches automatically and stays perpendicular to that edge. The frame attachment is not a separate handle. For mathematical content, see [LaTeX notes](../latex-notes/).
