## Rotate or resize a page

Use **Page Editing** mode to change page geometry. Rotating a page changes the saved page orientation. Annotations follow the page; this is different from choosing the paper orientation for a print job.

Resize page borders to add writing space or hide an outer area. This changes the page boundary, not the scale of its existing text and figures. The **Page Size** dialog allows precise dimensions. Its width and height refer to the underlying, unrotated page, so check the preview when working on a rotated page.

Cropping is not secure redaction: content outside a visible boundary can remain in the PDF. Keep an original copy before deleting pages or removing visible regions.

## Add a linked note page

Choose **Add Note Page**, then click where you want the reference on the source page. Mengshee appends a blank page, inserts a `see note 1.` reference and a corresponding heading, and opens the note page in an auxiliary pane. Note numbers are associated with the source page.

![A linked note page alongside its source](/mengshee/assets/note-pages.png)

Write or draw on the new page using the annotation tools. Save the PDF to preserve both the new page and its links. A note page is useful when a margin note would obscure the paper or a derivation needs more room.
