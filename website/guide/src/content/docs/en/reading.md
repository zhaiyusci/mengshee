## Navigate a document

Use the page number control to jump to a page, the thumbnail sidebar to inspect page order, and the contents sidebar to follow an existing outline. Search locates text that the PDF exposes as text; scanned images may need [OCR](../links-ocr/) first. Use fit-width or fit-page zoom to suit the reading task.

## Keep a reference beside the argument

Use a link's context menu to open its target in an auxiliary pane when that option is available. The original passage stays visible while you inspect the destination. Auxiliary panes are working views: you can navigate, select text, and annotate there. They are not screenshots.

The panes share the same document and editing mode. An edit in one pane belongs to that document, not to a separate copy. Each pane can independently use whole-page reading or Read by Views. Close a pane when you no longer need it; save the document to retain edits.

![A reference displayed beside the original reading position](/mengshee/assets/reference-panes.png)

## Choose the right display

Use ordinary whole-page reading for page layout and surrounding context. Use [Reading Views](../reading-views/) to read columns or regions in sequence on a smaller screen. Neither zoom nor opening a reference pane changes the PDF page itself.

If a link goes to the wrong place, inspect it in Cross-references mode rather than moving the visible text. A file link also depends on the linked file remaining available.
