## Define a reading path

A View is a reading region within a page. It helps you read columns or selected passages at a useful size on a small screen. It does not crop the PDF, modify the original page content, or recognize text.

Switch to **Reading Views** mode. Use **Draw** to mark regions; drawing continues until you leave the tool, for example with Esc. Use **Order** and click the regions in the intended reading sequence. The order is local to each page.

![Reading regions and their order](/mengshee/assets/reading-views.png)

## Generate and review

**Generate** can propose regions for the current page, all pages, or a chosen range. Pages with existing Views are skipped by default. Inspect the proposed regions and their order, then use **Apply**. Automatic proposals are a starting point: unusual layouts may need manual correction.

Enable **Read by Views** to navigate through those regions instead of whole pages. Whole-page reading remains available. An auxiliary pane can use its own whole-page or View-based reading setting, so a reference can remain visible while you read a column in the main pane.

Save the document after editing Views if you want to retain them. Use [page editing](../pages/) when you actually want to change the saved page boundary.
