# Withdrawn: LaTeX-Native Slide Editor Vision

The former proposal to develop Mengshee into a LaTeX-native slide editor has
been withdrawn. It is not the project's product direction or roadmap.

Mengshee focuses on PDF reading, annotation, proofreading, and editing,
including LaTeX-backed notes. Existing page editing and annotation features
remain supported; withdrawing the slide-editor vision does not remove them.

See the [README](../README.md) for the current project description and features.
