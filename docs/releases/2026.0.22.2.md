# Mengshee 2026.0.22.2

## Link border hotfix

Fix black rectangles appearing around newly created links after leaving Cross References mode, then disappearing when the PDF is reopened.

The link editor previously wrote a zero-width PDF border without updating the annotation object's cached border. It now updates both through the annotation API, so live rendering and saved/reopened rendering agree.

- Covers direct internal links, named-destination links, and external links.
- Preserves link targets and clickable rectangles.
- Does not remove intentional borders from existing links or hide the Cross References editing overlays.
- Also includes the toolbar-position fix from the local 2026.0.22.1 hotfix: icon-only mode tools stay on the right after toolbar rebuilding, mode changes, and layout restoration.

## Verification

The three new visual regression cases failed against the old backend and pass with the fix. They compare annotated page images immediately after leaving Cross References mode and after save/reopen, and verify link rectangles and targets.

The packaged runtime passes 58 Part tests, 52 toolbar tests, and 25 layout tests (135 passing results including initialization/cleanup; no failures or skips), plus an isolated PDF-opening smoke test. An existing external-link test was corrected to request rendering before querying lazily loaded link objects; its original failure was also reproduced on the previous runtime, and the corrected test passes on both.

Existing saved links do not need to be recreated. Save documents and exit Mengshee before installing. This installer is unsigned and may trigger a Windows SmartScreen prompt.
