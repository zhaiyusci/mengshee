# Mengshee 2026.0.23.0

## Note pages

- Add **Add Note Page** to the annotation toolbar, next to **Add Template Note**. Like the other annotation tools it arms on click, finishes after one placement, and is cancelled by Esc, right-click or another tool.
- Clicking a position performs one undoable operation: a blank page as large as the clicked page is appended at the end of the document, a named destination `mnote-<source page>-<sequence>` is added on it, a Link labelled `see note 1.` is written at the click, and the new page opens in an auxiliary frame so the note can be written without leaving the reading position.
- The link carries a self-contained `/AP` normal appearance stream: a pale note sheet, a thin border and the label in Helvetica-Bold from the standard 14, so a saved file embeds no font. The stream is added by the PDF generator through `Annot::setNewAppearance()`; the Poppler backend is untouched, one link adds exactly one Form XObject, and the label is visible in the live session, not only after reopening the file.
- The note page heading `note 1` is page content, written in the same page-insertion edit, so it survives annotation removal and prints with the document.
- Blank-page and dialog sizes now use PDF points instead of device pixels; **Insert Blank Page** and the **Insert Page** size fields produced pages `dpi / 72` times too large before.
- Undo removes the link, the destination and the page as one step, and the page image is refreshed last so the `see note 1.` label disappears with its link. Redo recreates all three; neither opens or closes a tab.

## Chinese translation

- Complete the `zh_CN` catalogue for the fork's own strings, including note pages, editing modes, reading views, LaTeX annotations and the application's own dialogs: 1769 translated messages, `msgfmt -c` clean.
- Fix translations that were present but unreachable because their `msgctxt` did not match the source context (the LaTeX toolbar actions, the annotation-popup `Template:` label, the auxiliary-frame fallback title, the point-unit suffix).
- Add the missing eIDAS signature-type labels.

## Building

- StemTeX is consumed as an installed, prebuilt runtime instead of a git submodule. The runtime is used in place and is neither copied nor rebuilt, and the pinned bundled release moves to **0.14.0**.
- QScintilla comes from that same runtime's release, so the LaTeX note editor needs no separate source checkout.
- The Windows build chain (SDK, application, installer) now lives entirely inside the checkout in `windows-build-workspace` and is driven by a single CMake script, `windows-build/cmake/build-windows-from-scratch.cmake`.

## Validation

- No functional code changed after the note-page test runs, so those results still describe this build. `parttest` covers the whole operation there: page count before the click, appended page size in points, `mnote-<page>-<n>` naming and sequence, link destination and rectangle, label and heading literals in the saved file, the heading actually being drawn, single-step undo and redo, save/reopen persistence, and the stale label after undo.
- Packaged smoke test: the staged `mengshee.exe` opened `autotests/data/file2.pdf` with the window title `file2.pdf - Mengshee`, closed normally, and loaded `okularpart.dll`, the Poppler generator and Poppler itself from the package; no module was loaded from the build workspace.
- Catalogue: `msgfmt -c` reports 1769 translated, 2 fuzzy and 4 untranslated messages, and the installed `okular.mo` contains the new strings.
