# Mengshee 2026.0.26.0

This release switches the default PDF backend to MuPDF and includes the fixes verified during the migration.

- Preserve custom LaTeX appearances when moving notes and use the correct physical units for layout width.
- Keep unreadable annotations from preventing the rest of a document from opening.
- Fix Windows OCR temporary-file replacement, isolate OCR font resources, and preserve edited word rectangles when saving.
- Share rectangle hit testing, handles, movement and resizing across annotations, callout boxes, OCR, links, Reading Views and page borders, while retaining each tool's colors.
- Allow flattened export when annotations overlap retained links or form widgets.
- Correct resizing of rotated pages, including cropped origins and PDF UserUnit scaling.
- Generate Windows print previews asynchronously for the current page at up to 72 DPI, cache page images, and discard obsolete results. Copies default to one and do not trigger preview rendering.

## Validation

The MuPDF backend suite passed 63 tests; rectangle interaction passed 5; asynchronous print preview passed 4 (all totals include initialization and cleanup). See [migration status](../mupdf-backend.md) for remaining feature limitations.

## Windows installer

The installer is `Mengshee-2026.0.26.0-Setup.exe`, accompanied by `SHA256SUMS.txt`.

Release page: [v2026.0.26.0](https://github.com/zhaiyusci/mengshee/releases/tag/v2026.0.26.0).

The packaged runtime passed the Zhai2026 PDF launch smoke test, loaded MuPDF, and loaded no project DLLs from outside its stage. Application and installer file versions are both `2026.0.26.0`. The installer is unsigned; an actual installation/upgrade has not been exercised.

Installer size: 57,451,788 bytes (54.79 MiB).

SHA256: `59ae585d3d3253ea41806bf792023d3c91e972536f5ebdfb82439f0da6d88514`

The PDF backend and UI PDF helpers share `MengsheePdfRuntime.dll`. Unused standalone Tesseract/Leptonica DLLs are omitted for MuPDF, and the installer uses LZMA2 ultra64 compression.

Windows CJK font substitution now resolves installed fonts through DirectWrite, including TTC face indices. The SDK omits Source Han Serif with `TOFU_CJK_LANG`, retaining DroidSansFallbackFull for systems without a suitable installed font. Embedded PDF fonts retain priority; documents using substitute fonts can change appearance. The installer is down from the initial 94.87 MiB package and the previous 67.16 MiB package, compared with 47.83 MiB for the Poppler release.

All 63 backend tests passed using the packaged runtime without SDK directories in PATH or standalone OCR DLLs (Qt Test and the offscreen platform plugin were supplied separately for the test harness). This includes pixel equality between unembedded Chinese text resolved from Windows SimSun and an embedded-font reference, save/reopen, and representative CJK glyph coverage in the Droid fallback. Print preview passed 4 tests and rectangle interaction passed 5. The final stage passed the PDF launch smoke test.
