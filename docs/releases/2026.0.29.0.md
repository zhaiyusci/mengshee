# Mengshee 2026.0.29.0

The new **Content Recognition** mode brings OCR and Reading Views into one workflow. Open **Recognize Content**, choose the current page, all pages, or a page range, and select the outputs you want.

- **Generate Reading Views** is selected by default. Use it on a PDF with selectable text to set a reading order for columns and figures while preserving the text layer.
- Select **Add searchable text (OCR)** for scanned pages. You can run it alone or together with View generation. Pages with existing text and pages with existing Views have separate skip options.
- Choose **Tesseract** for local processing with the bundled English model, or configure **GLM-OCR** or **Mathpix** for online recognition. When both outputs are selected, the online engines use one request per processed page.
- Review the proposed Views before applying them. A single undo restores the document after a combined operation.

The [English user guide](https://www.zhaiyusci.net/mengshee/guide/) and [Simplified Chinese user guide](https://www.zhaiyusci.net/mengshee/guide/zh-cn/) describe the workflow.

Download **Mengshee-2026.0.29.0-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
