# Mengshee 2026.0.30.1

Fixes the AI chat window in the installed application.

- The chat window kept its WebView2 data and its log next to the executable. In an
  installation under `Program Files` that folder is read-only, so the window could not
  start. It now uses `%LOCALAPPDATA%\mengshee\ai-chat`, with the temporary directory as a
  fallback, so it works from a read-only installation directory.
- Starting the chat window without Mengshee running now says so, instead of reporting a
  missing file path.

The AI chat window, its citations and the Markdown/MathJax rendering are otherwise
unchanged from 2026.0.30.0.

Download **Mengshee-2026.0.30.1-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
