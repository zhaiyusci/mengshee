# Mengshee 2026.0.30.1

The chat window shows what each answer cost, and can send pages as images again.

- Every answer carries a small line with the request's token usage: input, output and,
  when the service reports it, cached input with its hit rate. The window header keeps the
  session totals.
- **页面用图片** next to the send button sends rendered pages instead of the text layer: up
  to sixteen pages as JPEG, each preceded by `PDF page N:`. It is remembered between
  sessions. If the model rejects image input, the question is retried once as text and the
  option is switched off.
- The question box grows with multi-line input (Shift+Enter for a new line, Enter sends), and images can be attached with the **图片** button or by pasting a screenshot. Attachments are downscaled before sending and appear in the conversation.
- The page render request now returns JPEG (with a `mime` field) so an image turn stays
  small; PNG remains available on request.

Everything else is unchanged from 2026.0.30.0.

Download **Mengshee-2026.0.30.1-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
