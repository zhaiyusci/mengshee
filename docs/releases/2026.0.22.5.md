# Mengshee 2026.0.22.5

## LaTeX annotation diagnostics

- Show compilation errors directly as red text in the annotation appearance (AP), rather than leaving a blank result. Error appearances are rendered with Qt and do not depend on a working TeX compiler.
- Promote missing-glyph diagnostics to errors within each Mengshee snippet using a scoped `\tracinglostchars=3`. This is a general missing-glyph policy, not a command-specific workaround. StemTeX itself is unchanged.
- A corrected formula replaces the error appearance with its normal rendering.

## Popup editor caret

- Fix focus reentrancy when saving edited popup text on focus loss. The initial undo-stack notification must not restore the committing editor's own text and focus.
- Keep Qt and QScintilla focus state consistent, resolving the case where typing still worked but the native caret disappeared.
- Use the native QScintilla caret without adding a paint overlay. The caret remains steady, and actual undo/redo still restores text, selection and focus.

## Validation

- Packaged-runtime checks: 5 passed, 0 failed, 0 skipped, including initialization and cleanup.
- Coverage includes undefined commands, missing glyphs, corrected-formula recovery, native caret visibility, focus transitions and undo/redo.
- Tests used the staged DLLs and optional TeX tree, without SDK directories in the runtime search path. The staged GUI also opened and closed normally without loading SDK DLLs.
- No unrelated mode-switch matrix was run. Existing local PDF modifications and running installed instances were left untouched.
