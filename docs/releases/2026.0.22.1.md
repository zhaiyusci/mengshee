# Mengshee 2026.0.22.1

## Toolbar position hotfix

Fix mode tools moving away from the right edge when XMLGUI rebuilds the toolbars. The expanding spacer is now a registered XMLGUI action, and the second-row ordering is reapplied after rebuilding finishes. Icon-only controls and the one-to-many Apply icon are unchanged.

Regression coverage includes 48 scenarios across 1200px and 2500px windows, all editing modes, layout save/restore, and XMLGUI client removal/re-addition. Checks examine actual button positions, not just toolbar width.

The packaged runtime passed 52 toolbar tests, 48 Part regression tests, and 25 layout tests (125 passing results including initialization/cleanup, no failures or skips), plus isolated application startup/PDF loading checks. Packaged executable/Core/Part/PDF backend hashes match the build outputs.

No PDF format, annotation, or region-generation behavior changes are intended.

Save open documents and exit Mengshee before installing the update. The installer is unsigned and may trigger a Windows SmartScreen prompt.
