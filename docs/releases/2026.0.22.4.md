# Mengshee 2026.0.22.4

## 按 PDF 字体机制修正显示

- 移除绘制阶段按 Unicode 换成系统字体的本地覆盖逻辑，恢复 Poppler 按 PDF 编码与字体字形绘制的路径，不再逐字符增加例外。
- Windows 核心安装包随带完整的 14 种标准替代字体，包含 Symbol、ZapfDingbats；无需额外安装字体或 StemTeX。优先保留 PDF 自带的嵌入字体。
- 缺失普通字体按家族与粗体/斜体属性替代；外部字体按实际文件格式解析，保留字体集合 face index。
- 修正含中文安装路径的字体资源定位，并使字形边界计算与绘制使用一致的来源。

## 验证

- 包内字体专项：66 passed，0 failed，0 skipped；字形边界专项：4 passed，0 failed，0 skipped（计数含初始化/清理）。
- 覆盖 Standard 14、编码/ToUnicode、嵌入 CFF、横排/竖排 CIDToGID、Type3、Symbol/Zapf 字形与字宽、缺失字体样式、已有批注 AP 保存往返。
- 实际文档与 PDFium 视觉对照、SDK/安装包逐像素一致、无 SDK/TeX 的中文路径迁移验证、资源完整性负向测试与独立包启动均通过。
- 没有运行模式切换矩阵，没有修改用户 PDF 或运行中的安装版。

这是已有 PDF 显示机制的修复；没有重写新建 FreeText 的复杂文字排版/嵌入管线。技术边界和审计记录见 [PDF 字体说明](https://github.com/zhaiyusci/mengshee/blob/v2026.0.22.4/docs/pdf-font-rendering.md)。
