# Mengshee 2026.0.22.0

## Reading Views

- Automatically generate editable reading regions from the current page, a page range, or the whole PDF using local Tesseract layout analysis. No upload or OCR language models are required. Existing Views are skipped by default; generation is cancellable and its applied results form one undoable batch.
- Set reading order by clicking Views in sequence. Unclicked Views keep their relative order; numbering is independent on each physical page.
- Draw is now a toggleable tool with a checked state. Click again or press Esc to exit. Drawing and click-ordering are mutually exclusive.
- Reading-region tools are right-aligned, icon-only, and separate from the general View display menu. Apply uses a one-to-many icon; names and explanations remain available on hover.

## Numbered Callouts

- Click callout bodies or number badges to number them in the desired order, respecting document-wide or per-page numbering and the current label format.
- Internal IDs, text, and geometry stay unchanged, including when multiple callouts share an internal ID. Changes are undoable; locked affected annotations prevent partial updates.
- Number-badge hit testing handles native screen DPI, viewer rotation, and Read-by-Views projections.

## Windows download

- **Mengshee-2026.0.22.0-Setup.exe** — Windows x64 installer, including the optional bundled StemTeX TeX tree.
- **SHA256SUMS.txt** — checksum for the installer.

Automatic regions are editable suggestions, not guaranteed semantic document structure. Complex pages may need manual adjustments. These features do not crop or split physical PDF pages or change annotation permissions.

## Verification

Release-staged runtime checks: 25 layout-merger tests, 48 Part interaction/generation tests, and 4 toolbar tests passed with no failures or skips (counts include initialization/cleanup). This includes a 14-page real paper without OCR language models, four viewer rotations, and icon-only right alignment at 1200px and 2500px window widths. The staged application opens a PDF without loading project DLLs from outside the package.

The installer is unsigned. Windows may display a SmartScreen warning. Installer compilation, version metadata, staged binaries and checksums were verified; a full installation over an existing Windows installation was not performed.

Poppler and StemTeX dependency revisions are unchanged from 2026.0.21.0.
