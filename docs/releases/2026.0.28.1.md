# Mengshee 2026.0.28.1

A hotfix for Windows printing: the print dialog gains an original-size scale
mode, and its preview now matches the printed result.

## Fixes

- **Page Sizing & Handling → Scale mode** now offers **None; print original
  size** (Simplified Chinese: 原大小（不缩放）) alongside fit to printable area
  and fit to full page.
- The option follows the PDF backend's existing semantics: the selected paper
  size is kept, the page is printed at its own physical size (printer
  resolution / 72) centred in the printable area and clipped when it is larger,
  and only fit-to-full-page ignores margins.
- The print preview draws the page at that physical size inside the selected
  sheet instead of stretching it to the printable area. The paper size choice
  stays available, and its description continues to show the selected paper.
- The new strings are translated into Simplified Chinese, and the user guide
  describes the three scale modes.

## Validation

The print preview suite passed 8 tests, including two new scale-mode tests for
the options and the preview drawing. A packaged-runtime check opened the real
dialog through `Part::slotPrint`, confirmed the three choices, the preview's
original-size state and both print outputs. Printing an A4 page onto A3 paper
was compared: fit scales the page up to the sheet, while original size keeps
the A4 page at 100%, centred on the A3 sheet.
