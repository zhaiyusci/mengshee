# Mengshee 2026.0.28.0

Add another PDF to the document you are reading, in place.

## Features

- **File → Append PDF File...** appends every page of another local PDF to the
  end of the open document. The pages are imported into the live document, not
  written to a separate file: the normal save persists them, and one undo step
  removes everything that was appended.
- The append uses the same named-destination conflict choice as page
  insertion: **Add Suffixes** gives the appended destinations their own names
  and rewrites matching links, while **Keep Names As Is** keeps the original
  names.
- Appended pages keep their content, annotations, forms and links, and template
  notes are refreshed for the new page count.
- The action is available for local PDF documents, and its interface is
  translated into Simplified Chinese.

## Validation

The packaged runtime was checked for the appended page count, page geometry,
undo and redo (a multiple-page append, a one-page append and repeated cycles),
and save/reopen. The real menu action was also driven through its file dialog
and the named-destination conflict dialog.

The installer is `Mengshee-2026.0.28.0-Setup.exe`, accompanied by
`SHA256SUMS.txt`. The installer remains unsigned; a clean installation and an
