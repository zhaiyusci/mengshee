# Mengshee 2026.0.30.0

The AI question-and-answer feature now opens as a separate window with proper maths
typesetting, and the old in-application panel is gone.

- **Edit → AI Chat Window…** (`Ctrl+Shift+J`) starts the chat window from Mengshee. It reads
  the open document, keeps a conversation, and edits nothing in the PDF.
- Answers are Markdown; formulas are typeset with MathJax, so both inline and displayed
  mathematics render as they should.
- Citations in an answer are links such as `[Eq. (14)](pdf:12 "(14)")`. Clicking one brings
  the reader to that page, scrolls the evidence to the centre of the view and highlights
  the line. An answer without a printable label falls back to a page jump.
- The window belongs to its document: opening another document, closing it, or quitting
  Mengshee closes the chat window too.
- Model settings are shared: the window uses the **General AI** settings (base URL, model,
  API key) already configured in Mengshee. The key is never passed to the chat window.
- The window requires the Microsoft Edge WebView2 runtime, which ships with Windows 11.

The former in-application AI panel and its **Ask AI…** action have been removed; the
reading, annotation, page-editing, OCR and LaTeX note features are unchanged.

Download **Mengshee-2026.0.30.0-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
