# Mengshee 2026.0.30.0

The AI question-and-answer feature becomes a window of the application, with citations that
lead to the exact evidence.

- **Edit → AI Chat Window…** (`Ctrl+Shift+J`) starts the window. It is Mengshee's own child
  process and talks to the reader over its standard input and output, one JSON message per
  line: no port, no access token and no discovery file. The transport is the same on every
  platform.
- Answers are Markdown and formulas are typeset with MathJax.
- Citations are inline links such as `[the counterpoise correction is](pdf:7 "(12)")`.
  Clicking one opens that page, scrolls the line to the centre of the view and highlights
  it. The link text is asked to be copied verbatim from the page, which makes it
  findable; when the model writes no usable anchor, the window asks it once for the
  shortest verbatim quote on that page and locates that instead of falling back to a plain
  page jump.
- The window belongs to its document: opening another document, closing it, or quitting
  Mengshee closes the chat window.
- The **General AI** settings (base URL, model, API key) are shared, so the window needs no
  configuration of its own and the key never leaves the reader. Requests send no
  `temperature`; a new **Reasoning effort** field sends `reasoning_effort` when filled in
  and is dropped automatically if the service rejects it. The page is worded for any
  OpenAI-compatible service.
- The chat window keeps its WebView2 data and its log under
  `%LOCALAPPDATA%\mengshee\ai-chat`, so it works from an installation under `Program Files`,
  and it closes only with the permission it needs.

The former in-application AI panel and its **Ask AI…** action are removed; text search,
reading order, annotations, page editing, OCR and the LaTeX note features are unchanged.

Download **Mengshee-2026.0.30.0-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
