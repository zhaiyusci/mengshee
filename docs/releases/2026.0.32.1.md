# Mengshee 2026.0.32.1

AI chat windows are now tied to the document that opened them.

- Every document gets a stable id. The chat window title and header show it, so
  two documents with the same file name no longer look identical.
- Opening the chat again from the same document raises its existing window
  instead of doing nothing.
- On Windows the chat window is owned by the reader window: it follows the
  document window when it is minimized or closed and stays associated with it.
- Each document uses its own WebView2 data directory, so multiple chat windows
  can run at once without sharing browser state.
- Saving or renaming a document updates the chat window title through the
  existing reader/chat protocol.
- Document and chat window titles no longer include the PDF backend name; the
  backend remains available under **Help → About Backend**.
- The 2026.0.32.0 vector print work and the 2026.0.31.0 MuPDF parity work are
  included.

Download **Mengshee-2026.0.32.1-Setup.exe** for Windows. **SHA256SUMS.txt** contains the installer checksum.
